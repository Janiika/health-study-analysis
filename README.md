# HÄLSOSTUDIE ANALYS

Ett individuellt analysprojekt på en hälsostudie, del 1.

## Projektets innehåll
- Beskrivande analys
- Simulering kopplad till caset
- Konfidensintervall
- Hypotesprövning

## Dataset
Datasetet innehåller deltagarnas information om:
- Ålder
- Kön
- Längd
- Vikt
- Blodtryck
- Kolesterol
- Rökstatus
- Sjukdom

## Miljö
- Python version 3.14
- Bibliotek `pandas`, `numpy`, `matplotlib` (see `requirements.txt`)

## Kör projektet
- pip install -r requirements.txt
- jupyter notebook: `report_del1.ipynb`
