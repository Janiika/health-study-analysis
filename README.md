# HÄLSOSTUDIE ANALYS

Ett individuellt analysprojekt på en hälsostudie, del 1.
Innehållet i detta projekt är:
- Beskrivande analys
- Simulering kopplad till caset
- Konfidensintervall
- Hypotesprövning

## Miljö
- Python version 3.14
- Libraries `pandas`, `numpy`, `matplotlib` (see `requirements.txt`)
